# Manual do professor

Selecione uma turma e siga o fluxo `resultado → habilidade → intervenção → acompanhamento`. O portal permite atividades, provas, frequência, registros de aula, materiais, comunicados e correção. Notas e feedback devem ser confirmados antes do salvamento. Arquivos precisam respeitar finalidade pedagógica e não devem conter PII desnecessária. Use relatórios e jornadas somente dentro das turmas autorizadas.
