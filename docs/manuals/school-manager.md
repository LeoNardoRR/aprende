# Manual do gestor escolar

Use a visão institucional para acompanhar turmas, matrículas, usuários, avaliações, indicadores e alertas da escola. Operações de vínculo e movimentação preservam histórico. Convites devem atribuir apenas o menor papel necessário. Exporte dados somente para finalidade autorizada e trate arquivos exportados como informação protegida.
